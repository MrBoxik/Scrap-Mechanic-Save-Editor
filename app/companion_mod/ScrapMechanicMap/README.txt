SURVIVAL MAP COMPANION

This is a standalone Scrap Mechanic Custom Game based on vanilla Survival.
Each new world keeps Scrap Mechanic's own random seed and stores exploration
progress in that save. It does not require the Save Editor or an overlay.

CONTROLS

1. Select Map Tool in the hotbar.
2. Primary use opens or closes the full map.
3. Secondary use changes the full-map zoom.
4. Escape closes the full map.

WHY A TOOL?

The official Workshop Lua API does not expose a safe arbitrary global M-key
binding for Player scripts. A dedicated tool avoids replacing the vanilla
Logbook key or modifying game files.
