# Support

## Before reporting a problem

1. Close Scrap Mechanic and restart the editor.
2. Confirm that you are using the newest release.
3. Try **Save edited copy** rather than writing to the active game save.
4. Check that the save still opens normally in Scrap Mechanic without edits.
5. Read `%LOCALAPPDATA%\ScrapMechanicSaveEditor\editor.log` for the latest error.

## Good bug reports include

- editor version and Scrap Mechanic version;
- Windows version;
- the exact action that caused the issue;
- whether it happens with one save or every save;
- the relevant part of `editor.log`;
- a screenshot if the issue is visual.

For Map Companion problems, also include:

- whether Steam and Scrap Mechanic are on different drives;
- the Map Companion settings used;
- `%LOCALAPPDATA%\ScrapMechanicSaveEditor\map-companion-launch.log`;
- whether the problem affects the minimap, M-key full map, or both.

The editor's **Settings → Installation check** is the fastest way to confirm
that Steam, Scrap Mechanic, local profiles, and the optional Mod Tool were
detected. Do not replace those paths with another user's paths.

Save databases can contain Steam IDs, world names, player state, inventory, and
other personal gameplay data. Do not attach a save publicly unless you have
reviewed it and are comfortable sharing it. A small reproducible copy is best.

Use the repository's bug-report template when Issues are available. For private
support, contact MrBoxik on Discord using user ID `638802769393745950`.
