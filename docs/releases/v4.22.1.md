# Scrap Mechanic Save Editor 4.22.1

Windows 10/11, 64-bit. Portable release; no Python installation required.

## Download and Run

Download **ScrapMechanicSaveEditor-4.22.1-Windows-x64.zip**, extract the complete
folder, and open **ScrapMechanicSaveEditor.exe**. Keep the **_internal** folder
beside it. GitHub's automatic Source code archives are not the Windows app.

This is the fast-starting folder build, not a single-file executable that must
unpack its runtime each time. The ZIP contains the executable and all required
application runtime files. A Steam installation of Scrap Mechanic is required.

## Highlights

- Modern desktop editor for inventories, player/world state, progression,
  character profiles, blueprints, and external backup history.
- Searchable 2D world map, reusable HD map captures, and an interactive 3D world.
- Survival Map Companion with a live minimap, M-key full map, persistent
  exploration, waypoint details, and adjustable in-game settings.
- Shared centered waypoint symbols and consistent map navigation.
- Cached-map reuse, image-load recovery, native minimap motion improvements,
  and protection against old results appearing after a world change.
- Fix for exploration history being replaced by an older file during an
  in-flight background save. Failed writes retain unsaved history.
- Save/profile write protection while the game is running and checks against
  overwriting a save that changed on disk.

## Before Editing

Close Scrap Mechanic completely and keep your own backup. Automatic versions
are stored outside the game's save folders. Map Companion is read-only and
works only in Survival; it does not require developer mode or a game-file patch.
